# Drivhus Plant Card

Et simpelt, moderne Lovelace-kort til visning af drivhus-sensorer:

- Jordfugt
- Jordtemperatur
- EC (Næring)
- Dynamisk status

## Installation via HACS

1. Gå til HACS → Integrations → Custom repositories
2. Tilføj URL til dette repository
3. Vælg kategori: `Lovelace`
4. Installer kortet
